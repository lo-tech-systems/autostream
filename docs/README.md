# autostream Documentation

This is the documentation for autostream and the autostream dial accessory. Pick a page below, or start with Getting Started if you're setting up for the first time.

## Getting started

- [Getting Started](GETTING-STARTED.md) - install autostream on a Raspberry Pi and complete initial setup.
- [Playing your first track](FIRST-TRACK.md) - connect a source and start streaming, once Input 1 and a default speaker are set up.

## Everyday use

- [Home Page](HOME-PAGE.md) - the main day-to-day screen: what's playing, and which speakers are active and how loud.
- [Equaliser](EQUALISER.md) - tone and level controls for the shared output stage, applied after all sources are mixed.
- [Service](SERVICE.md) - track turntable maintenance: stylus wear, drive belt life, and main bearing oil life.
- [Multi-Appliance](MULTI-APPLIANCE.md) - view and control another autostream appliance on the same network from the one in front of you.
- [Speaker Synchronisation](SPEAKER-SYNC.md) - measure how far out of step your speakers are and apply timing offsets to fix it.

## Setup

- [Setup: Inputs](SETUP-INPUTS.md) - configure Input 1, Input 2, and the Bluetooth source, including pairing a Bluetooth turntable.
- [Setup: Playback Defaults](SETUP-PLAYBACK.md) - set the default speaker and volume.
- [Owntone Setup](SETUP-OWNTONE.md) - AirPlay settings that don't fit on the main Setup page: buffered audio, per-speaker modes, and output offsets.
- [Setup: Track Identification](SETUP-TRACK-ID.md) - turn on track identification so autostream shows a real title, artist, and artwork.
- [Dials (Setup)](SETUP-DIALS.md) - the appliance side of setting up an autostream dial.
- [Personalisation](SETUP-PERSONALISATION.md) - appearance and multi-appliance-visibility switches for the Home page and web UI.
- [System & Updates](SETUP-SYSTEM.md) - hostname, mDNS discovery timing, SD card wear monitoring, and software updates.
- [Factory Reset](SETUP-FACTORY-RESET.md) - return the appliance to first-run Wi-Fi setup mode.

## Appliance and system

- [Info](INFO.md) - autostream's About/status screen: component versions, service health, and appliance status.
- [System Maintenance](SYSTEM-MAINTENANCE.md) - keeping an appliance healthy over time: updates, update channels, and removal.
- [Advanced Operations](ADVANCED.md) - install options, including choosing the OwnTone backend.
