# Showcase pictures

Pictures of the dials for the website and print.

- `hd-now-playing-jazz-1024x600.png`: the HD dial's now-playing page with the speaker list, at 1024x600.
- `hd-appliances-1024x600.png`: the HD dial's appliance list, with a turntable playing and a CD player idle.
- `hd-equaliser-six-band-1024x600.png`: the HD dial's six-band equaliser page.
- `hd-pulldown-1024x600.png`: the HD dial's pull-down panel open, with screen settings and the dial's details.
- `spi-now-playing-rock-rich@2x.png`: the small SPI dial's now-playing screen in the rich layout, scaled up two times.

They are generated by `tools/showcase` from invented music and generated cover
art, so no real artists or artwork appear. To regenerate them, run
`python tools/showcase/capture.py` from the repository root; see
`tools/showcase/README.md` for the options.
